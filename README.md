# InterTwined Learning

This repository is a conference poster, created in Twine, for the VALA Conference 2026. 
The poster file is index.html, and the other files in this repository are supplementary material. 

The Twine story was created in Twine 2.12.1 using the story format Harlowe 3.3.9. 

Title: InterTwined Learning - Using the indie game tool Twine to create a library eLearning module
Abstract: A story of disaster, innovative uses of game-development tech, and accidentally winning over the eLearning specialists. Months were spent working to adapt library training content into a H5P online module. After much trial, the module was completed and just waiting to be published. And then overnight the organisation's eLearning platform underwent an update, causing a H5P error and months of work was gone in an instant. Oh no! Not only that, but the eLearning platform was so affected that being able to use H5P on the platform at all was delayed indefinitely. Instead of conceding defeat, this embattled librarian re-created the module using Twine – a free open source software used for creating text adventure games. Twine's built in linking, interactivity and use of HTML meant that the module could be recreated in a clean and simple interface. Then the module was uploaded and hosted publicly on GitHub to bring it to the library audience. Not only did this unlock a new creative method of creating training content, but this workaround also got the tick of approval from the eLearning team and inspired cross-departmental creativity.
